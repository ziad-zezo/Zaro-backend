# E-Commerce Backend

Backend API for an e-commerce platform, built with Node js.

## 🚀 Features

- User authentication & authorization
- JWT-based authentication
- User registration and login
- Products management
- Categories management
- Shopping cart
- Orders management
- Order status tracking
- Product search and filtering
- Admin capabilities
- Secure API endpoints

## 🛠️ Tech Stack

- Node js / Express js
- MongoDB
- JWT
- REST API
